# What Kind of Index Is This?

**Preferences → Sorting** opens with a question rather than a setting: what
kind of index this project is. **Subject**, **name**, **title**,
**authorities** or **first line**.

It is worth answering. A name index and a subject index do not file alike, and
neither of them files like a table of authorities: a name index needs the
prefix lists that put *van der Meiden* under M and *De Geer* under D, a title
index needs the leading articles ignored so *The Quality of Mercy* files under
Q, and an authorities index files by citation rather than by word. Those are
not preferences so much as the definition of the index you are building.

## Declaring is an event, not a mode

Choosing a kind fills the filing settings below it with that kind's defaults
**once**. From then on they are this project's settings and yours to edit.
Nothing re-applies them behind you.

That matters when you read a setting back. An option that is off means you
switched it off, not that it was never seeded — and if the two were
indistinguishable, every reopening of this page would be an invitation to
re-seed settings you had deliberately changed.

## A declaration never takes a setting away

Declare a name index, then change your mind and declare a subject index, and
the name index's prefix lists stay where they are. **Seeding adds; it does not
remove.**

If you want those lists gone, clear them yourself. That is a good deal better
than the application silently emptying six lists you may have spent an
afternoon editing, on the strength of one dropdown.

## If you never answer

A project that has never been asked is a **subject index**, which is the
commonest answer and the one that changes least.

If your index is one of the other four, declaring it is the single most useful
thing you can do to its filing, and it costs one choice. The per-language
filing tables — the Dutch and German prefixes, the Irish and Māori rules, the
declared alphabets — are seeded from this answer, so an index that has never
been declared reaches none of them.
